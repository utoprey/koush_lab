Программы

OpenNFT

OpenNFT — программный комплекс для тренинга с нейрообратной связью по фМРТ в реальном времени и автоматической оценки качества данных. Он объединяет компоненты на Python и MATLAB для гибкой организации экспериментов.

  • Обработка данных фМРТ и нейрообратная связь в реальном времени
  • Автоматическая оценка качества в реальном времени (rtQA)
  • Модульная реализация на Python и MATLAB
Репозиторий GitHubДокументация

pyOpenNFT

pyOpenNFT — Python-фреймворк для фМРТ в реальном времени и нейрообратной связи с использованием ЭЭГ. Он предоставляет модульные процессы обработки данных и поддерживает предсказание сигналов фМРТ по обработанным записям ЭЭГ с помощью машинного обучения.

  • Обработка фМРТ в реальном времени на Python
  • Предсказание фМРТ по ЭЭГ для нейрообратной связи
  • Модульная обработка и оценка качества
