Software

OpenNFT

OpenNFT is an integrated software package for real-time fMRI neurofeedback training and automatic quality assessment. It combines Python and MATLAB components to support flexible experimental workflows.

  • Real-time fMRI data processing and neurofeedback
  • Automated real-time quality assessment (rtQA)
  • Modular Python and MATLAB implementation
GitHub repositoryDocumentation

pyOpenNFT

pyOpenNFT is a Python framework for real-time fMRI and EEG-informed neurofeedback. It provides modular processing workflows and supports machine-learning prediction of fMRI signals from processed EEG recordings.

  • Python-based real-time fMRI processing
  • EEG-informed fMRI prediction for neurofeedback
  • Modular processing and quality assessment
